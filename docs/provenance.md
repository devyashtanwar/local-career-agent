# Publication and evidence provenance

This repository was assembled from the project's local setup artifacts and design
notes on 15 November 2026. Original PC work was performed in visible Cmux SSH
sessions. Publication preparation did not install or change anything on that PC.

Included: inference bootstrap and tests, pinned model metadata, OpenClaw policy
template, guarded launchers, synthetic result summaries, current setup/finding
documents, detailed workflow diagrams and dated research.

New for publication: home-independent configuration rendering and its filesystem
tests, install/preparation wrappers around the recorded commands, public README,
runbook, security/contribution/license documents, normalized links and portable
Obsidian Canvas. Those packaging changes have not been replayed on a fresh Linux
host; they must not be described as a new hardware installation test.

The example configuration's generated gateway token was replaced with a marker.
Usernames/home paths were generalized. A container ID was removed from the
selected inspection record. Result values were otherwise preserved. No selected
result contains a real candidate's professional dossier.

Not included: private notes-vault backups, raw agent/session transcripts, SSH
details, internal machine addresses, full gateway health/state dumps, actual
configuration tokens, browser profiles or duplicate superseded planning exports.
Their useful conclusions are represented in the public docs. This avoids turning
a notes backup into a public repository by accident.

Research documents retain primary links and explain when selected source files
were read at pinned revisions versus mutable branches. They are not newly rerun
tests of those third-party projects. The repo does not vendor third-party code,
model weights or the upstream sandbox Dockerfile; downloads retain upstream terms.

See [VALIDATION.md](../VALIDATION.md) for publication checks and limits, and
[findings](findings.md) for hardware observations and failures.
