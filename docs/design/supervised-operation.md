# Supervised operation

Proposed behavior; account automation is not deployed.

The operator should use a verified professional dossier, an exact one-page PDF
renderer and a persistent ledger. The dossier includes dated experience, real
skill proficiency, project ownership and demos, verified metrics, education,
approved answers, exclusions and writing samples. A resume is an output of that
knowledge, not the whole knowledge base.

Use shadow mode first: synthetic pages and local drafts. Review the exact packet
and destination before any live form entry; fields may transmit before Submit.
If later permitted, bounded action classes need explicit destinations, facts,
volume caps, expiry and stopping conditions. A few supervised successes are not
evidence of reliable autonomous behavior on every portal.

Unknown or sensitive declarations, consent changes, MFA, CAPTCHA, independent
assessments and contracts go to a human. Do not automate account creation/password
resets or read a primary mailbox for OTPs as a fallback. Future mail integration
should use separate least-privilege OAuth and narrow tools. A Gmail search label
is a workflow filter, not a credential-level permission boundary.

Social engagement cards should contain a post link, context, action, reason and
editable draft. The target is useful participation and relationships, not merely
job advertisements or activity volume. Human review/publishing remains the pilot
boundary. Platform permissions must be established independently of browser ability.

Human-like navigation may mean waiting for page state and writing naturally. It
must not mean evading automation controls or concealing assessment assistance.
Only truthful visible resume content is in scope. No hidden qualification stuffing
or instructions intended to manipulate an ATS are implemented.

n8n could own polling, review waits, deadlines, notification dispatch and event
history. OpenClaw could then execute bounded drafting/operator work. Use one
scheduler and action ledger, with permissions covering every alternate write path.
Do not add n8n merely to duplicate a working queue.
